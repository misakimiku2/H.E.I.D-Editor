# H.I.D.E v1.5.0

> 发布于 2026 年 9 月 25 日 · 标签 `v1.5.0`

本版把手机和电脑直连起来：手机扫一下电脑上的二维码，就能接着编辑电脑上的文件。局域网直连，没有账号、没有云中继，内容不出你所在的网络。

## 设备互联

- 新增了电脑端的共享开关：在菜单栏「菜单」旁边的互联按钮里打开，端口可改，关掉立即释放端口。
- 新增了手机「扫一扫」配对：点顶栏那颗直接开相机，对准电脑上的二维码即可连上。
- 新增了不需要相机的等价入口：粘贴配对码、6 位短码、手填 32 位配对码。
- 新增了免扫重连：配对过一次后，下次启动自动连回那台电脑，也可以一键「连接到某台电脑」。
- 新增了远程文件树：在手机上浏览电脑那个目录，直接打开、修改、存回电脑。
- 新增了「电脑上正打开的文件」列表：手机点一行就接管桌面正在看的那个文件（有未保存改动的不接管，先在桌面存盘）。
- 新增了桌面改动的实时推送：电脑上改、建、删文件，手机上那棵树秒级跟上；打开中的文件走差异时间线提示。
- 新增了离线队列：手机断网或杀掉后台时保存的改动存在手机上，重连后自动写回电脑。
- 新增了冲突保护：断连期间桌面也改过的文件会标出来要你逐条确认，两边都不会被覆盖。
- 新增了多设备配对：可以记住多台电脑，同一时间服务一台，已配对设备能单独移除。
- 新增了共享状态的常驻可见：桌面状态栏「手机可访问 · 目录」，入口按钮上一颗状态点（灰=没连上、绿=已连接、琥珀=在等一等、红=要你确认）。
- 新增了「测试配对模式」（带「开发用」标记）：跨机调试时不用专门有人在电脑旁点「允许」。

## 其他

- 新增了 13 种语法高亮，覆盖到 31 种：ini、toml、makefile、dockerfile、hcl、protobuf 等。
- 优化了安卓与平板的弹窗、设置与列表触点，统一抬到 48dp。
- 优化了扫码器的镜头选择与变焦手感：默认只用主摄，捏合只管变焦，切镜头不再黑屏一闪。
- 优化了设置与设备互联面板里的说明文字。

## 问题修复

- 修复了配对成功后记住的「电脑地址」其实是对端设备名、导致下次启动自动重连连不上的问题（安卓）。
- 修复了手机上刚扫完码就显示「已连接」、之后做什么都没反应的问题，现在会显示「等待电脑上确认」。
- 修复了手机连上后不显示电脑名字的问题。
- 修复了配对被拒时把原因写成「对端已关闭连接」、实际是桌面自己拒绝的问题。
- 修复了文件超过远程打开上限时，把实际大小和上限显示成同一个数的问题。
- 修复了桌面文件监视漏掉 `node_modules` 那一档黑名单的问题，一次安装依赖会涌进推送。
- 修复了「已开启，尚无设备连接」这句状态在手机上说的其实是电脑的问题。

> v1.4.x → v1.5.0 是同一把签名，安卓**直接覆盖安装即可**，不用卸载；装过 v1.3.x 及更早 debug 包的设备需先卸载一次。
