# H.I.D.E v1.6.0

> 发布于 2026 年 10 月 19 日 · 标签 `v1.6.0` · 本版仅桌面

本版给 Windows 资源管理器带来一套专属文件图标：把 H.I.D.E 设为默认打开方式后，.md、.txt、日志还是代码文件，看图标就能分清。

## 新功能

- 32 种文件类型在资源管理器里有了专属图标：延续应用图标的深蓝窗口与红黄绿三圆点设计，每种格式一个专属颜色加白色标签（TXT、MD、LOG、JSON、TS、PY、RS……），小图标到大图标各视图都清晰
- CSV 表格文件可以直接关联用 H.I.D.E 打开，配合表格网格视图使用
- 各格式独立注册系统关联：资源管理器「类型」列会显示「H.I.D.E Markdown 文档」这样的具体名称，不再是一句笼统的「文本与代码文档」

## 说明

- 之前已经把 H.I.D.E 设为默认打开方式的用户：升级后在「设置 → 默认应用 → 按文件类型」里重新选一次 H.I.D.E，专属图标即刻生效（系统会记住选择，之后的升级不用再选）
- 右键「用 H.I.D.E 打开」与 App Paths 启动方式不受影响
