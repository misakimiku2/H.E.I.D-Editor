# H.I.D.E v1.3 发行说明（v1.3.0 / v1.3.1）

> 发布日期：2026-09-18（v1.3.0 当日补丁 v1.3.1） · 标签：`v1.3.0` / `v1.3.1`

## v1.3.1 补丁：更新文档自愈

发行说明的「写入」机制随 v1.3.0 上线——**v1.2 及更早版本的客户端点更新时不落盘**，
直升 v1.3 的用户在更新重启后不会自动打开更新文档，「关于 → 更新文档」入口也因
文档列表为空而不渲染。v1.3.1 增加启动自愈：发现当前版本在文档列表中缺失时，
静默抓取一次 `latest.json`，其版本号恰与当前一致就把说明补种回列表——
补种后立即自动展示一次，入口随之出现。latest.json 已指向更新版本（有新版可用）
或条目已存在时不动作；浏览器模式无更新通道，不受影响。

以下为 v1.3.0 的完整发行说明。

## 一、结构化内容与新格式（路线图主体）

### 1. JSON / YAML 结构化视图：树 + 分屏

`.json` / `.yaml` / `.yml` 默认进入结构树视图，工具栏「树 / 分屏 / 文本」三档切换：

- 树浏览：默认展开前两层，折叠态显示 `{n}` / `[n]` 计数与值摘要，双击标量复制原值；
  全部展开 / 收起；单容器子节点超 500 只渲染前 500（折叠态零渲染成本）。
- **分屏视图**：左结构树 + 右源码，两侧按比例同步滚动——点树定位源码，滚源码跟树。
- 「格式化」按钮缩进规范化（走统一编辑链路，可撤销）。
- YAML 经 js-yaml 动态 import（懒加载 chunk，不进主包）；循环引用（`&anchor` / `*alias`）
  以占位节点截断。解析失败或超 200 万字符自动退回文本视图。

### 2. Markdown 增强：大纲导航与图片资产管理

- **大纲导航浮窗**：贴预览视图右缘的毛玻璃弹窗，常驻把手收展；滚动跟随高亮当前标题；
  条目按标题层级折叠（右键一键展开 / 折叠全部）；点击跳转——预览可见时滚动定位，
  编辑器可见时跳行，分屏两者都做。
- **粘贴图片自动落盘**：Markdown 页签粘贴 / 右键「粘贴图片」→ 剪贴板读图写入
  `<文档目录>/assets/paste-时间戳.png` → 光标处插入相对路径引用（预览直接可见）。
  加载失败的图片可右键删除；从文档删除受管理图片后自动清理本地文件（8 秒延迟防误删）。
- **图片本地化**：菜单一键收集全文 `![](http…)` 远程图源逐张下载到 `assets/remote-*`
  并替换为相对路径；进度走通知卡片，完成后展示失败明细。下载复用安全护栏
  （仅 http/https、15 秒超时、单张 5MB 上限、单文档 50 张）。
- **导出 HTML 带代码高亮**：导出的单文件 HTML 中代码块按 Prism 内联着色，主题随深浅色。

### 3. CSV 只读态排序与筛选

- 列标右键升序 / 降序 / 取消（数值按数值比、文本本地化比较、空值恒排最后）；
  编辑栏漏斗输入按子串筛选任一列。**视图变换不改写数据**，行号始终显示原始行号，
  状态栏显示「已显示 N / M 行」。
- 排序 / 筛选生效期间增删行列、填充柄等结构操作自动降级禁用，单元格编辑仍可用。

### 4. 打印 / 导出 PDF

- `Ctrl+P` 或菜单「打印…」调起系统打印（WebView2 打印对话框自带「另存为 PDF」）。
- 按文档类型路由：Markdown 走渲染管线（含代码高亮）、CSV 转打印表格（不随筛选视图）、
  文本 / 代码带行号等宽排版。二进制与大文件预览禁用；安卓无打印对话框不显示入口。

## 二、标签拖拽与多窗口（路线图外）

浏览器式的标签体验，仅桌面端（安卓触屏不启用，浏览器模式仅栏内重排）：

- **栏内重排**：按住标签拖动，其余标签实时让位，被拖标签平滑滑动到落点。
- **拖出脱离成窗**：拖出标签条松手即在该位置（光标落点）新建独立窗口装载文档，
  未保存内容随行；唯一标签脱离后源窗口自动关闭。
- **跨窗口合并**：标签拖到另一窗口的标签条上出现占位指示，松手并入指定位置并激活；
  同路径标签去重只聚焦。标签右键菜单新增「移到新窗口」。
- **按窗会话恢复**：重启后所有窗口按原样还原（含各窗口位置与尺寸）。
- 拖拽采用系统原生 OLE 拖拽：拖拽图像全局跟随光标，跨越窗口边界无歧义。

## 三、SVG 可视化编辑（路线图外）

SVG 工作台从「左源码 + 右预览」升级为「编辑 | 预览」双模式（工作台右上角切换，
状态随页签持久化）。定位是**微调 AI 生成图的工作视图**，不做 Inkscape：

- **点选元素**：画布上直接点选（选中框随缩放恒定线宽），Esc / 点空白取消。
- **检查面板**（右侧）：**属性**——填充 / 描边 / 粗细 / 透明度，`<text>` 可直接编辑文本，
  颜色控件复用内置取色器；**图层**——只读结构树与画布选中双向联动；**颜色**——
  调色板列出文档内全部用色，一键全局换色（单条历史，一步撤销）。
- **拖拽移动 + 方向键微调**：拖动过程只改渲染副本，松手才提交；方向键按用户单位平移
  （Shift ×10）；Delete 删除元素（根元素不可删）。
- **手术式写回**：每个元素解析时记录源码区间，修改只替换该元素的文本——
  注释、缩进、未触碰部分逐字保留；撤销 / 重做 / 脏标记 / 保存 / 草稿全部复用文本链路。
- **PNG 导出**：1x / 2x / 4x 存盘或直接复制到剪贴板（透明背景）。
- 画布平移改为中键拖动；编辑 | 预览分隔条可拖拽调宽（[20%, 80%]，持久化）。
- **安全不倒退**：画布渲染的是脱敏副本（脚本不执行、无内联事件、无外链请求），
  源码与磁盘文件永不因渲染脱敏被改动；XML 解析失败自动退回纯预览模式。

## 四、文件树与窗口体验（路线图外）

- **文件树自动刷新**：递归监视根目录（桌面），外部增删改文件自动反映到树中，
  已展开的子目录与错误状态在刷新后保留，无需再手动刷新。
- **跨文件搜索增强**：扫描移出主线程不卡 UI，命中窗口按 CJK 宽度感知截取（中文上下文不再错位），
  结果分页展示；文件树侧栏宽度可拖拽调节并持久化。
- **会话恢复提速**：多文件并行读盘 + 「恢复中」占位，重启后不再先闪一帧欢迎页再跳文档。

## 五、更新体验（路线图外）

- **启动必检**：去掉 24 小时节流——此前发版后 24 小时内启动的客户端收不到提示。
- **更新说明成为文档**：发现新版本即写入更新说明，安装重启后自动打开一次
  **只读更新文档标签页**（本篇即其内容来源）；之后可在「关于 → 更新文档」重看，
  并可展开回看过往版本的更新文档（最多保留 20 份）。瞬态标签不进会话快照，不会重复弹出。

## 六、缺陷修复（选摘）

| 修复 | 说明 |
| --- | --- |
| 关闭激活标签闪现欢迎页 | 关闭标签同步选中继任者并在绘制前提交，不再闪现欢迎页 |
| 粘贴图片预览失败 | Windows 混合路径分隔符致 fs 插件读取失败 → 路径归一跟随文档目录原生分隔符 |
| 页签内文档高亮错位 | 块级图片 URL 改写改变偏移基准 → 移除改写、行内操作按块内选区逐块应用 |
| 分屏同步滚动掉帧 | 任意 setState 击穿预览 memo 致全篇重跑渲染管线 → 按块记忆化 + 大纲跟随下沉（仅展开时监听） |
| 标签拖拽误脱离 | Chromium 在 dragstart 中折叠源元素会令 dragend 过早触发 → 源标签改半透明 + 早到 dragend（<200ms）按取消处理；顺带修复重排右移差一位 |
| 原生拖拽被拦截 | 禁用 tauri 默认拖放拦截，修复 🚫 光标 / 拖拽浮影不可见 / 跨窗合并失效 |

## 七、升级注意事项

- 桌面更新走 minisign 签名校验（`latest.json` + `.sig`），校验失败即中止，不会安装被篡改的包。
- 标签拖拽在**应用窗口之外**（桌面 / 其它应用上方）的空隙处光标显示 🚫 属 OLE 系统行为，非缺陷；
  窗口内拖拽正常。
- 多窗口为同进程实现：真·第二进程仍会被单实例插件弹回并聚焦已有窗口。
- 安卓为侧载 debug 签名，覆盖安装无需卸载旧版；release 签名计划于 v1.4 补齐。
- SVG 编辑模式对畸形 XML 自动降级为纯预览；触屏为基本可用（pointer events），
  专门适配随安卓移植流程另行安排。
