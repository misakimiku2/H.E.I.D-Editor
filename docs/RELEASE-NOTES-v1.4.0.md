# H.I.D.E v1.4 发行说明

> 发布日期：2026-09-21 · 标签：`v1.4.0`

## 主题：安卓全面触屏适配 —— 从「能看」到「能用」

v1.4 是一个**移动端专项版本**。桌面端功能与交互零改动：所有触屏分支由
`IS_TOUCH_PRIMARY`（pointer: coarse）、`isPhone` 与 Tailwind 的 `pointer-coarse` 变体门控，
桌面代码路径不进这些分支。安卓版自此不再是「能打开文件的桌面壳」——长按出菜单、
捏合缩放、拖拽平移、系统分享、SAF 里直接建文件改名删除，都按触屏习惯重做了一遍，
并改用 release 签名发布 APK。

手机（<768px）与平板（≥768px）都覆盖：平板沿用桌面布局并放大到触屏人体工学，
手机用自己的顶栏 + 底栏骨架。

## 下载与升级

| 渠道 | 说明 |
| --- | --- |
| 桌面应用内更新（推荐） | 启动 4 秒后自动检查（每次启动必检），或「关于」弹窗手动检查；确认后自动下载安装并重启 |
| 桌面手动安装 | `H.I.D.E_1.4.0_x64-setup.exe`（NSIS 简体中文向导，含更新签名校验） |

> ⚠️ **安卓老包升级必读**：v1.4.0 起 APK 由 debug 签名改为 release 签名。装过 v1.3.0
> 及更早 debug 包的用户**必须先卸载再安装 v1.4.0**（签名不一致，系统禁止覆盖安装），

> 应用内更新提示也会照常弹出。

> 📌 **本版桌面端没有功能变更**，桌面用户可跳过本次更新。

## 一、触控基建：把鼠标依赖一项项换掉

- **长按 = 右键**：标签栏、文件树、Markdown 预览（图片 / 图表 / 空白处）、大纲、JSON 结构树、
  CSV 网格全部接入右键菜单的触屏变体（行高 44dp、面板 280dp、毛玻璃质感与桌面同款），
  触发时给一次轻触觉。
- **文本选择让位系统**：源码编辑器与 Markdown 预览里长按文字一律交给系统选字——
  自绘菜单不再和原生选择工具条抢同一个手势。
- **hover 隔离**：所有 hover 样式收进 `@media (hover: hover) and (pointer: fine)`，
  触屏设备永不触发；页面 10px 自定义滚动条只留在桌面，触屏退回系统悬浮条（不占布局宽度）。
- **触点达标**：菜单栏、标签栏、状态栏、查找替换栏、下拉菜单、各弹窗按钮统一放大到
  44–48dp 命中区。
- **快捷键提示门控**：`Ctrl+…` 这类提示只在**接入物理键盘**时显示（外接键盘经
  `InputManager` 枚举与插拔事件上报，软键盘天然排除），没键盘时不再出现看不懂的空提示。

## 二、手机端补齐

- **文件树抽屉化**：改覆盖式抽屉，从顶栏纯图标入口开合——图片查看器的入口随之回归
  （此前文件树在手机端整个隐藏）。
- **精简状态栏**：只留语言 · 编码 · 换行 · 行列，编码与换行可点切换，弹层与桌面共用一套。
- **键盘避让**：底栏按钮沉到键盘后方、信息栏精确贴住键盘上沿、输入时光标自动滚入可视区、
  顶栏高度计入状态栏安全区（此前顶栏按钮会被裁一截）。

## 三、SAF 文件管理（在安卓上管自己的文件夹）

- 文件树上**直接新建 / 重命名 / 删除**（经 Kotlin 桥解析 document URI），删除走二次确认；
  改名后旧 URI 失效由前端承接并换绑新路径。
- 树根行显示真实目录名（`primary%3ADownload%2Fnotes` 解出 `Download/notes`），不再是编码串。
- 剪切 / 复制 / 粘贴、在文件管理器中显示：安卓系统不提供，置灰而非假装可用。

## 四、查看器：捏合与平移

- **图片**：双指捏合缩放（锚点 = 双指中点，与桌面滚轮的锚点数学同源）、单指平移、
  双击回到 1:1，工具栏按钮触屏 44dp。
- **SVG 编辑画布**：空白处单指拖动 = 平移画布（替代桌面中键），双指捏合 = 缩放；
  元素拖拽优先于平移，拖动中途捏合不会丢掉未提交的移动。
- **SVG 预览面板**：同一套单指平移 + 双指捏合（本版补齐，此前只能中键拖、滚轮缩，
  平板上等于不可用），复位走右下角工具条。
- **SVG 检查面板与取色器**：属性行、图层树行、色板、删除按钮、取色圆点全部触屏尺寸；
  取色浮层在触屏下加大色块与滑条（色相/透明度滑条 28dp）、按实测尺寸做屏幕内翻转钳制，
  小屏上不会顶出边界。

## 五、CSV 网格触屏化

- 长按弹出与桌面同款的**单元格 / 行号 / 列标**菜单，触屏额外补上：全选、向下填充、向右填充、
  行列移动、行高列宽步进——桌面靠拖拽做的事都有非拖拽出口。
- **选区延展把手**替代桌面的填充柄（Sheets 同款：拖动延展选区，配菜单填充）。
- 全部拖拽改用 Pointer 事件：WebView 只为点按合成鼠标事件、拖拽过程中不发 `mousemove`，
  这是桌面好用而平板点不动的根因。
- 单击选中、再点同一格进入编辑；手机端顶栏补网格 / 文本切换。

## 六、平板（≥768px）专属一轮

- **文件树改桌面同款推拉式**：挤压编辑区而非盖上去，可拖动调宽（触屏把手加宽到 12dp）；
  手机仍是覆盖抽屉。
- **菜单栏常驻纯图标按钮**（44dp）：打开文件 / 保存 / 撤销 / 重做 / 从网址导入 / 设置 /
  分享 / 文件夹树开合，高频动作不用先开菜单；低频项（最近、另存为、快捷键、关于）留在主菜单。
- **系统分享**：安卓没有打印对话框，改为「分享」——调起系统分享面板，把当前文件内容
  发出去；超出 Binder 传输限额时前端先拦并说明原因。
- **弹窗适配**：设置面板 560→760dp、关于面板 320→416dp，标签与行高同步放大，
  按钮达 44dp；触屏下隐藏弹窗内滚动条与顶部小关闭钮（关闭走点外部 / 完成 / 系统返回）。

## 七、Markdown 编辑与预览的触屏操作

- 选中文字后，选区上方浮出**操作工具条**：复制 / 粘贴 / 全选 / 一键重复上次格式化命令 / 更多。
  「更多」打开与桌面同一份格式菜单（触屏格子 70×60）。
- 长按空白处仍是插入菜单；长按文字则让位系统选字。
- 修掉一处触屏浮层误触：长按抬手时合成的 `click` 会顺手关掉浮层甚至误执行一条命令
  （文件树里可能是「删除」）——现在只认浮层挂载之后真实发生过的 `pointerdown`。
- 编辑视图切换（三档 / 两档、格式化按钮）在触屏下整体放大。

## 八、质量与验证

- 单元测试 822 → 828 全绿，`tsc` 干净，前端构建通过。
- 平板模拟器（1280×800，系统字体缩放 1.3×）逐屏量取可点元素 `getBoundingClientRect`：
  主要触点 ≥44dp（关键操作 48dp），1.3× 字体下不破版、无横向溢出；真 touch 事件实测
  单指平移位移与手指位移逐像素一致、双指张开 100→250px 得缩放 ×2.5（锚点为双指中点）、
  小地图与侧栏 / 编辑区分隔条可拖、CSV 选区把手可延展。
- 桌面回归：右键菜单尺寸与条目、快捷键提示、滚轮缩放与中键平移逐项复核零变化
  （触屏分支全部由 `IS_TOUCH_PRIMARY` / `isPhone` / `pointer-coarse` 门控）。

## 已知限制（本版未覆盖，下一版补）

> 本节两条在 v1.4.1 复核时按代码实测改写（表格那条原记述有误：触屏出口其实自 v1.1.0 就在，
> 真实问题是尺寸没量过）。已发布的 GitHub Release 正文保持原样，勘误只落在仓库这份
> ——它是「关于 → 更新文档」回看历史版本时的来源。

- **Markdown 表格的行 / 列增删**：触屏出口自 v1.1.0 就有（点选单元格浮出「行+ / 行− / 列+ / 列−」
  工具条），但按钮只有 32px 高，低于 v1.4 自己定的 ≥44dp 触屏档，也没有测试覆盖。
  v1.4.1 抬到达标并补上覆盖。
- **源码编辑器的行号槽**（点选整行、拖动多选、悬停提示）在安卓整体关闭，未做触屏版。
- **平板标签页关闭按钮 28×28**：嵌在标签内部，扩到 48dp 会与相邻标签命中区重叠；
  替代路径是长按标签出菜单关闭。
- **SVG 元素位置微调只能拖拽**：桌面的方向键步进在触屏上不可用，属性面板也没有 X/Y 输入框。
  v1.4.1 补输入框与 ± 步进。
- **打印 / 导出 PDF 在安卓无入口**（WebView 无系统打印对话框），可用系统分享或桌面端打印。
- **外部修改检测 / 文件监听**安卓不做（SAF 无真实路径），文件被别处改过需重新打开。
