# H.I.D.E v1.6.1

> 发布于 2026 年 11 月 9 日 · 标签 `v1.6.1` · 本版仅桌面

这一版把「正改着没保存，软件崩了会怎样」这条线补齐：未保存内容最坏只丢 3 秒，已保存的文件不再可能被写坏，重启后自动把没保存的内容端回来并告诉你它是什么时候的。另外压掉了桌面上那个不属于本软件的浏览器右键菜单。

## 改进

- 未保存内容每 3 秒落一次草稿。之前是「停下笔 3 秒后才写第一次」，一直打字就一次都不落盘，崩溃会丢掉整段本次编辑；现在首笔编辑当场就有副本，最坏只丢 3 秒
- 保存改成原子写：内容先落同目录的临时文件、确认写进磁盘，再一次性替换目标文件。以前是先把原文件截空再往里写，正好崩在那一瞬间会换回一份被截断的真实文件——那比「这次没存上」严重得多
- 重启后恢复出未保存内容时，左下角说一条：几个文件、分别是哪几个、这份草稿最后记录于多久之前。以前只有标签上一个小脏点，看不出这份内容是上次没保存的，还是磁盘上后来又被别处改过
- 两种「这一份其实没有草稿保护」的情况会当场告诉你，不再闷声不管：单份超过 200 万字符（卡片上直接带「立即保存」，保存一次就重新有副本）；这台设备的本地存储写不进去（配额满或被隐私模式禁用）
- Markdown 预览正文的最大宽度从 900 放宽到 1280，宽屏上不再只占中间一条

## 问题修复

- 修复了桌面上右键弹出浏览器原生菜单（返回 / 刷新 / 另存为 / 打印 / 更多工具）的问题：欢迎页、状态栏、预览空白处、预览里的图片都不再出现。本软件自己的右键菜单不受影响，输入框里的剪切复制粘贴也照旧

## 说明

- 崩溃恢复的边界要说清楚：单份超过 200 万字符的内容不进草稿（会提示你），大文件的分块预览与二进制只读本来就不改内容，也不进草稿
- 保存的那一瞬间会在同目录出现一个 `原名.数字.数字.heidtmp` 的临时文件，文件树和全盘搜索都不显示它；如果真的崩在改名之前，目录里会留下这么一个，手动删掉即可
- 本版仅桌面：安卓的更新清单版本不动，手机不会提示，改动里的前端部分随下一版安卓一起出
