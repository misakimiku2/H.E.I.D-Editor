# H.I.D.E v1.4.2

> 发布于 2026 年 9 月 23 日 · 标签 `v1.4.2`

本版把「用别的应用打开 H.I.D.E」这条链路修通了，并让桌面与安卓知道对方也存在。改动集中在安卓端。

## 新功能

- 新增了其他应用「分享 → H.I.D.E」：分享文件直接打开，分享一段文字会落成一个新的未命名草稿（安卓）。
- 新增了「关于」里的另一端入口：桌面端给出安卓版 APK 二维码，扫码即下；安卓端给出桌面版下载页与「打开下载页」。
- 新增了更新链的国内镜像与多源回退：GitHub 取不到时自动改用 Gitee 镜像；检查更新失败不再静默，会在「关于」里留痕并给出可复制的下载链接。
- 新增了触屏上的取色入口：长按选中色值后，浮出的选区工具条里有「取色」（安卓）。
- 安卓代码文件里选中文字后有了选区工具条：复制 / 粘贴 / 全选 / 取色 / 更多，「更多」就是桌面右键那份同样的编辑菜单。

## 问题修复

- 修复了从其他应用「打开方式」选 H.I.D.E 后文件不会被打开的问题——应用只是正常空启动（安卓）。
- 修复了 `.md` `.py` `.csv` 等文件在系统「打开方式」列表里根本看不到 H.I.D.E 的问题（安卓文件关联）。
- 修复了代码文件里选中文字后没有任何复制 / 粘贴 / 全选入口的问题（安卓、平板）。
- 修复了手机顶栏文件名前的圆点显示成灰色、看着像「未保存」的问题，现在与标签栏、标签抽屉一致（当前文件为绿色）。
- 修复了安卓文件树里「在文件中搜索」入口照常出现却什么都搜不到的问题（SAF 目录不支持跨文件搜索，已收起该入口）。
- 修复了「关于」弹窗在矮屏或横屏时底部内容被裁掉的问题，现在超长可滚动。
- 修复了从外部应用打开一个已在标签里、且有未保存改动的文件时，改动被磁盘内容直接盖掉的问题（现在只把该标签切到前台）。

> v1.4.1 → v1.4.2 是同一把签名，**直接覆盖安装即可**，不用卸载；装过 v1.3.x 及更早 debug 包的设备需先卸载一次。
> 桌面端本版只有「关于」里的安卓版二维码与更新链的国内镜像，不在国内网络里可以跳过本版。
