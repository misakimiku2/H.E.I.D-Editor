# H.I.D.E v1.3.3 发行说明

> 发布日期：2026-09-19 · 标签：`v1.3.3`

## 主题：CSV 网格编辑器——编辑修复 + 交互批次

本补丁集中处理 CSV 网格编辑器：修掉一组同根因的编辑焦点缺陷（含一处向上拖行
丢失整批行的数据事故），随后补齐与表格软件对齐的交互能力——拖拽重排、多选、
自适应表格大小、逐行行高与单元格内换行。

### 编辑修复（三个症状，同一根因）

- **双击编辑回归**：双击单元格的编辑框此前开启当帧即被关闭（双击第二下 mouseup
  注册的 rAF 晚于 dblclick 执行，把焦点从编辑框抢走触发误提交），表现为双击
  「完全没有反应」。现在双击 / F2 稳定进入就地编辑。
- **编辑栏打一个字就被提交**：在顶部编辑栏输入时焦点被单元格编辑框抢走，触发
  编辑栏 blur 误提交并把焦点落回网格——后续按键被当作网格快捷键解释。
- **退格清空整格**：在编辑栏按两下退格，第二下落回网格按「清空选中格」执行，
  整格内容消失。修复后编辑栏逐字编辑，Enter 才落盘，Esc 取消。
- 根因修复：单元格编辑框与顶部编辑栏共用编辑状态时，焦点接管与 blur 提交语义
  按编辑发起来源（cell / bar）区分；输入法组词中的 Enter / Escape 不再误触发
  提交或取消。

### 数据安全

- **行拖拽丢行事故修复**：向上拖动行时网格被按「目标行数」截断，第 4 行拖到
  第 2 行会导致其后所有行从数据中消失。现在互换 / 插入 / 扩齐全部只增不减，
  并附与事故场景一致的回归测试。

### 拖拽重排

- **互换**：按住列标（或行号）拖到另一列（行）上松手，整列（行）内容互换，
  目标列（行）高亮、源标减淡、选区跟随，手动列宽随内容一起换位。
- **插入式移动**：对准列间 / 行间网格线（±8px / ±5px 热区）时该线高亮，松手
  改为插入——源位抽走、其余顺移。拖到数据区外的空白列 / 行等于移动过去。
- 移动阈值 4px 区分点击选择与拖拽；排序 / 筛选生效期间结构操作照例禁用。

### 选择与填充

- **Ctrl 多选**：Ctrl+点击 / 拖拽向选区追加更多不连续区域；Ctrl+点击已选中的
  格子收拢为该格。复制按选区顺序逐块拼接，Delete / 右键清空作用于全部选区，
  Ctrl+Enter 铺满所有选中格。

### 自适应表格大小

- 编辑栏新增「自适应表格大小」按钮：一键完成**列宽按内容实测**（长文本列真正
  撑开，封顶 200 显示宽单位）+ **行高按折行数**（每行文本 20px，单行行保持默认）
  + **自动开启单元格换行**。
- 新增独立「换行」开关：开启后多行内容按列宽折行显示（不再压成 ⏎ 单行截断），
  状态随标签页持久化。

### 行高与换行编辑

- **逐行行高**：拖动行号底边调整该行高度（16–400px，实时预览），双击底边或
  右键「恢复该行默认行高」还原；右键菜单的紧凑 / 标准 / 宽松三档作为未调整行
  的默认值；行高按标签页持久化。虚拟滚动与命中判定按逐行位置前缀和计算。
- **单元格内换行**：单元格编辑框升级为多行文本域，Alt+Enter 换行（Enter 仍是
  提交并下移），内容行数多时编辑框自动增高；顶部编辑栏同步支持多行显示与编辑。
  含换行的字段提交时按 RFC 4180 自动加引号。

### 其他

- 快捷键帮助弹窗新增「CSV 表格」分组，补齐本次新增的手势与快捷键说明
  （F2 / 双击编辑、Alt+Enter 换行、Ctrl 多选、拖拽重排、行高调整等）。
