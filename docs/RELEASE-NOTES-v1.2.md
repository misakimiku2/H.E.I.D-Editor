## 一、大文件与跨文件检索（v1.2 路线图主体）

### 1. 超大文件打开——三层分级

打开路由（选择器 / 最近 / 文件树 / 拖拽 / argv / 会话恢复）统一先查文件尺寸再分流：

| 文件大小 | 行为 |
| --- | --- |
| ≤ 32 MB | 正常可编辑 |
| 32 MB ~ 512 MB | 只读分块预览（`LargeFileViewer`） |
| > 512 MB | 拒绝打开并给出替代建议 |

- Rust 侧（`src-tauri/src/large_file.rs`）单次顺扫统计行数并构建**自适应稀疏行偏移表**
  （条目超 2M 步长翻倍稀释，内存 ≤ 16MB）；按行窗口读取（CRLF 剥离、超长行 1MB 截断、
  单窗口 4MB 预算）；UTF-16 按码元扫描换行。
- 前端虚拟滚动（滚动条代理映射 + sticky 行块，超浏览器布局上限按比例压缩）+ 换窗去抖防竞态 + 跳转到行。
- 编辑出口：从预览中**提取当前窗口到可编辑新标签页**；大文件标签不进外部文件监听
  （避免整读做 diff 基准）。

### 2. 跨文件搜索

文件树侧栏内嵌搜索态（不新增常驻面板），按需一次全量扫描、无索引、无常驻后台：

- Rust `search_in_dir`：黑名单 / 隐藏目录与 symlink 跳过，> 32MB 与二进制文件跳过并计数；
  逐文件复用既有编码检测解码，按行匹配，支持**大小写 / 正则 / 全词**；
  结果收集 1000 条上限、计数全量、扫描 2 万文件封顶。
- UI：Enter 触发，分组列表 + 命中高亮 + 统计条，Esc / 关闭回到文件树；
  点击命中打开文件并定位到行列（脏标签不重读磁盘直接定位）。
- 安卓 SAF 无递归枚举，搜索入口在移动端隐藏。

### 3. 查找上限解除

解除单文件 200 万字符扫描与 5000 匹配上限：全量计数、
「全部替换」全文一次替换不再截断。受 CM6 渲染约束，装饰高亮仍限 5000 条，
状态栏显示「共 N 处（仅高亮前 5000 处）」。

### 4. 小地图大文件适配

- 修复 canvas 单边 65535 设备像素的浏览器硬上限：旧实现大文件下小地图**永久空白**；
  现在画布尺寸只由「容器可见高度 × dpr」决定（结构性保证永不越界），只绘制可见行窗口，
  绘制量与文档规模无关，点击 / 拖拽 / 滑块映射语义不变。
- 大文件（> 200 万字符）**不再连带关闭小地图与语法高亮**：CM6 高亮本就是视口级惰性解析，
  实测 12.7MB / 31.5 万行的 `mermaid.js` 打开瞬间语法树仅覆盖 0.775% 而视口已着色。
- 大文件降级只剩：补全 / 选区匹配 / 自动缩进（> 1000 行即关）与粘性滚动。

### 5. 十六进制查看

只读 hex 视图（16 字节/行：偏移 + hex + ASCII），与「二进制 · 只读」状态自动衔接；
二进制判定升级为 16KB 采样（大文件深处的 NUL 也能识别）。

### 6. 撤销历史自适应降档

内容超 400 万字符自动把 200 条全文快照降至 5 条并在状态栏提示，
50MB 级文件连续编辑不再线性吃内存。

## 二、路线图外的体验增强

### Mermaid 图表：预览、可视化表单编辑与右键菜单

- Markdown 预览内渲染 Mermaid，图表支持编辑弹窗（可拖动调整栏宽）与格式化工具。
- 编辑器按图型拆分为**结构化表单**（节点 / 连线 / 数据项等），覆盖流程图、时序图、
  饼图、XY 图、甘特图、时间线、思维导图；遇不支持的内容降级为只读提示。
- 预览支持「适应宽度 / 原始尺寸」切换；宽图按住鼠标拖动平移；图表右键菜单（编辑 / 删除）。

### 代码内颜色圆点与轻量取色器

- 颜色字面量（hex 3/4/6/8 位、rgb/rgba、hsl/hsla 含现代写法与百分比）前内联渲染色样圆点；
  视口级扫描，大文件成本与文档大小无关。
- 点击圆点弹出零依赖取色器（SV 色块 + 色相 / 不透明度滑条 + Hex 输入），
  拖动实时回写源码，序列化保留原格式家族（位数 / 大小写 / 函数名 / alpha 规则）。
- 撤销分组走应用层历史：整段拖动一条 Ctrl+Z；新增设置项「颜色标记」（默认开）。

### Windows 外壳集成

- NSIS 安装钩子在安装完成后补齐 Tauri 未覆盖的注册项：出现在「打开方式」候选列表、
  「设置 → 默认应用」，以及资源管理器右键「用 H.I.D.E 打开」（任意文件类型）。
- 已装用户无需重装可运行 `npm run register:shell` 补注册，`unregister:shell` 完整撤销；
  全部写入 HKCU，不需要管理员权限。

## 三、缺陷修复

| 修复 | 说明 |
| --- | --- |
| 浏览器模式粘贴弹授权框 | 右键菜单粘贴探测改走只读权限查询，未授权时静默降级聚焦编辑器；CSV 网格 Ctrl+V 放行原生 paste 事件免权限接流，不再触发「查看剪贴板」授权弹窗 |
| 大文件命令注册缺失 | 补注册 probe / read_line_window / read_byte_window / file_size 命令与 LargeFileIndex 状态，修复大文件功能运行时报错 |
| 安卓编译失败 | 渲染窗口 builder 的 focused / skip_taskbar 参数限定桌面平台 |

## 四、升级注意事项

- 桌面更新走 minisign 签名校验（`latest.json` + `.sig`），校验失败即中止，不会安装被篡改的包。
- v1.2.0 的文件关联 / 右键菜单注册由安装包自动完成；覆盖安装旧版后若未生效，
  运行一次 `npm run register:shell`（见 `docs/RELEASE.md`）。
- 安卓为侧载 debug 签名，覆盖安装无需卸载旧版；release 签名计划于 v1.4 补齐。
