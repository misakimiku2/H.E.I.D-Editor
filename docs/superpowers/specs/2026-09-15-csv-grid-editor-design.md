# CSV 可视化网格编辑器 — 设计文档

日期：2026-09-15
状态：已与需求方逐节确认

## 背景与目标

H.I.D.E 目前对 CSV 没有任何特殊处理：`.csv` 文件按纯文本打开，几千行逗号挤在一起无法阅读和编辑。需求方此前用 Google Sheets 编辑 CSV，希望在 H.I.D.E 内完成同样的核心工作流：**点击单元格直接输入内容**，并配合框选、下拉填充、区域复制粘贴等常规表格操作。

产品定位约束：本项目是轻量文本编辑器，依赖保持干净；网格编辑是"CSV 的工作视图"，不是要做一个电子表格软件。

## 需求清单（已确认）

| 项 | 结论 |
|---|---|
| 数据规模 | 几千行左右 → 行虚拟滚动必需 |
| 核心操作 | 单元格点击输入、增删行/列、首行作表头、区域复制/粘贴 |
| 框选输入 | 选区直接打字 + Ctrl+Enter 铺满选区；Delete 清空选区 |
| 下拉填充 | 填充手柄拖拽：单格重复、多格循环、纯数字等差递增 |
| 分隔符 | 逗号/分号/制表符自动识别，保存沿用检测到的分隔符 |
| 列宽 | 按内容自适应（钳制）+ 拖拽调整 + 双击边界恢复自适应 |
| 编辑栏 | 网格顶部：单元格地址框 + 内容输入框（同 Excel 编辑栏） |

## 一、视图模型

- `.csv` / `.tsv` 文件的页签语言标记为 `csv`，**默认进入网格视图**；工具栏（markdown 视图切换按钮同位置）提供"网格 / 文本"切换，文本视图即现有 CodeMirror。
- 页签新增 `csvView: 'grid' | 'text'` 视图状态（模式对标 markdown 的 `mdView`），随会话持久化。
- 首行表头：默认把第一行渲染为置顶加粗表头（仍可正常点击编辑），工具栏提供开关；开关状态记在页签上。
- 状态栏追加 `行 × 列` 与当前分隔符显示；编码显示沿用现有。
- 空文件/新建 `.csv`：渲染约 30 行 × 8 列的"幽灵空网格"，点击即可输入；未写入内容的尾部区域保存时自动裁剪，空表保存为空文件。
- 编码有损解码（含 U+FFFD）的文件照常允许网格编辑，与现有文本编辑行为一致。
- 二进制检测命中（`tab.binary`）的文件不提供网格，只开文本视图。

## 二、数据流与架构

核心原则：**网格不拥有数据，`tab.content` 字符串是唯一事实**。

```
tab.content (CSV 文本)
   │ parseCsv(text, delimiter)      ← useMemo，仅 content 变化时重解析
   ▼
string[][] 网格模型（+ 幽灵行列）
   │ 编辑（输入/粘贴/填充/增删行列）
   ▼
serializeCsv(grid, delimiter, eol) → 新文本 → updateTabContent()
```

### 新增模块

- `src/lib/csv.ts`：纯函数集合。
  - `parseCsv(text, delimiter): string[][]` — RFC 4180：双引号转义（`""`）、引号内含分隔符/换行；容忍末行无换行；不规则行补齐到最宽行。
  - `serializeCsv(grid, delimiter): string` — 最小引号策略（仅在字段含分隔符/引号/换行时加引号），引号翻倍；尾部整行/整列全空裁剪；统一以 `\n` 序列化，换行风格由保存链路按 `tab.eol` 转换。
  - `detectDelimiter(text): ',' | ';' | '\t'` — 统计引号外各分隔符出现频次取众数，平票取逗号。
  - `computeFill(source, target): string[][]` — 填充规则（复制/循环/数字递增）。
  - 列宽估算：按显示宽度扫描各列最长内容（CJK 记 2），钳制 [6, 40] 字符。
- `src/components/CsvGridEditor.tsx`：网格组件，props 为 content + onChange（App 侧对接 `updateTabContent`）。

### 关键机制

- **每一笔编辑 = 一次 `updateTabContent()`**：撤销/重做、脏标记、diff 时间线、草稿、外部修改检测全部自动复用，零额外代码。
- 输入过程中的击键只存在于浮动输入框/编辑栏的本地状态，**提交才触发序列化**，避免边打字边全量重解析。几千行 × 10 列的单次解析在毫秒级，提交频率下无性能问题。
- 保存/编码写回（Rust `write_text_file` + encoding_rs）/换行符转换完全走现有链路，网格层无感知。

## 三、网格行为

### 选区与编辑

- 点选单元格；拖拽 / Shift+点击 / Shift+方向键框选；Ctrl+A 全选。
- 点击行号/列标选中整行/整列，Shift+点击扩展多行/多列。
- 双击、F2 或直接打字进入单元格编辑：Enter 提交并下移，Tab 提交并右移，Esc 取消；编辑中方向键移动光标不移动选区。
- 框选后直接打字 → 输入进活动格；**Ctrl+Enter 将该值铺满整个选区**（不含递增规则，递增仅填充手柄）。
- Delete / Backspace 一次清空整个选区（单步撤销）。
- 键盘导航：方向键移动活动格，Home/End 行首行尾，Ctrl+Home 回首格。

### 下拉填充手柄

- 选区右下角小方块，向下/向上/向右拖拽，途中高亮预览目标区并提示将填入的值，松手应用：
  - 单格 → 重复该值；
  - 多格选区 → 循环重复（1,2 → 1,2,1,2）；
  - 源区全为纯整数/小数 → 等差递增（1,2 → 3,4,5）。

### 剪贴板（与 Sheets/Excel 互通）

- 复制/剪切选区 → 系统剪贴板写 TSV 纯文本；剪切 = 复制 + 清空。
- 粘贴 → 按制表符解析（复用 parseCsv，支持引号内多行），从活动格起覆盖，行列不足自动扩展。
- 每笔剪贴板操作单步撤销。

### 行列操作

- 行号/列标右键（复用现有 `ContextMenu` 组件）：在上方/下方插入行、在左侧/右侧插入列、删除选中行/列。
- 均为一次 `updateTabContent`，撤销照常。

### 编辑栏（formula bar）

- 网格顶部固定：左侧单元格地址框（活动格如 `B3`；框选时显示 `B3:D5`），右侧内容输入框完整显示活动格内容。
- 输入栏编辑 = 编辑活动格：Enter 提交、Esc 取消，与网格内编辑同一条提交路径。

### 列宽

- 默认按内容自适应：解析时单趟扫描各列最长显示宽度（CJK 记 2），钳制 [6, 40] 字符；宽度随内容变化在下次解析时更新。
- 列边界拖拽调整；双击边界恢复该列自适应宽度。
- 手动列宽记在页签上（跟会话走，不持久化到文件）。

## 四、性能

- 行虚拟滚动：固定行高（约 28px），只渲染可视区 ± 缓冲行；表头与行号列 sticky。列不虚拟化：个人数据列数少，超过 128 列的文件网格仍可打开，但交互与渲染未针对该场景优化。
- 性能闸门：文件 > 5MB 或 > 5 万行时默认以文本视图打开，顶部提示条提供"仍要用网格打开"。
- 网格视图下全局查找替换栏禁用（提示切文本视图）。

## 五、边界处理

- 列数不齐 → 补齐到最宽行；保存裁掉尾部全空行列；空表存空文件。
- 引号转义、内嵌逗号/换行完整支持；保存最小引号（与 Google Sheets 导出行为一致；手工精调过引号风格的文件往返会被规范化，属可接受行为，编辑栏视图可作核对）。
- 换行符：网格序列化统一 `\n`，写盘换行风格沿用现有 `tab.eol` 保存链路。

## 六、明确不做（YAGNI）

公式、排序、筛选、单元格样式、多 sheet、网格内查找替换、单元格级撤销粒度、列数虚拟化。
