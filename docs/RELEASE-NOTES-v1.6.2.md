# H.I.D.E v1.6.2

> 发布于 2026 年 11 月 9 日 · 标签 `v1.6.2` · 本版仅桌面

这一版把查找和文件树搜索的手感补齐：查找栏不再只能待在弹出时的位置，按住除输入框外的任何地方都能拖走；文件夹搜索现在同时匹配文件名与文件内容，找文件不必再靠记忆猜它在哪儿出现过。另外修了深色模式下搜索命中文字发黑、树底与设置按钮不跟主题的问题。

## 改进

- 编辑器查找栏（Ctrl+F / Ctrl+H / Ctrl+G）与 Markdown 预览查找栏支持拖动：按住栏面除输入框外的任意位置（按钮、间距都行）即可把栏挪开；轻点按钮仍是正常点按，拖起来后不会误触按钮。拖动始终被约束在窗口内，不会拖丢
- 文件夹树搜索同时匹配**文件名**与**内容**：结果顶部单列「文件名匹配」一组，点击直接打开；内容命中照旧按行分组并带高亮。大小写 / 全词 / 正则选项对两者同时生效，隐藏目录与临时保存文件依旧跳过
- 文件名匹配默认最多列出前 200 个，组标题给总数；避免搜一个常见字母把结果区刷屏

## 问题修复

- 深色模式下，文件夹树搜索命中的高亮文字不再用浏览器默认的黑字，跟随当前主题文字色；文件名命中与内容命中的两处都已修正
- 文件夹树面板底色改为跟随应用内主题，不再在「应用浅色 + 系统深色」时留一块深底
- 设置弹窗底部「完成」按钮补上深色配色，深色下不再是一块刺眼的白色按钮
- 新增主题来源守卫测试：源码里再出现 `dark:` 变体或绕开 `useTheme` 读系统深浅色，测试会直接报出文件与行号

## 说明

- 本版仅桌面：安卓的更新清单版本不动，手机不会提示；安卓侧载包仍停在 v1.5.5，这些前端改动会随下一版安卓包一起出
