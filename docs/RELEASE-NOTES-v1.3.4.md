# H.I.D.E v1.3.4 发行说明

> 发布日期：2026-09-20 · 标签：`v1.3.4`

## 主题：CSV 网格编辑器——键入错序与多行粘贴覆盖两修

本补丁修掉上一版交互批次暴露的两个 CSV 网格缺陷，其中一处属于数据破坏类。
全部修复附先复现旧缺陷、再转绿的回归测试。

### 键入进编辑：字符次序颠倒（输入 20 得 02）

- 单击选中单元格后直接打字（键入即替换整格内容进入编辑，Excel 习惯），第二个
  字符此前会插到最前面——「20」变成「02」。
- 根因：程序化聚焦输入框时光标停在文本开头，而键入的首字符已在开启编辑时代入
  单元格，后续字符便依次插到最前。现在焦点接管后光标自动落到文本末尾。
- 附带行为变化（与 Excel F2 语义一致）：F2 / 双击进入已有内容的单元格编辑时，
  光标落在内容末尾（方便接着补内容），不再是开头。

### 多行粘贴覆盖下方行（数据破坏）

- 在一格上粘贴带换行的多行文本（如从别处复制的一段文字），此前会被当作表格
  粘贴——按行拆成「3 行 × 1 列」从当前格向下写入，下方行的内容直接被覆盖。
- 现在分三层处理，「段落进一格」与「表格拆行」两类场景各得其所：
  - **单格目标 + 纯文本多行（无制表符）**：整段含换行写入一格（提交时按
    RFC 4180 自动加引号），下方行不再受影响。拆行粘贴的出口保留：先框选多行
    区块再粘贴，仍按行拆开写入。
  - **剪贴板双通道（纯文本 + HTML）**：复制 / 剪切同步写入 HTML 表格结构，
    粘贴时优先按 HTML 解析。网格内复制一列再粘贴、从 Excel / Google Sheets
    粘贴多行单元格，都按真实表格结构落位，多行单元格复制粘贴不再散架。
  - **编辑态右键粘贴**：双击进入编辑后右键粘贴，此前会先提交编辑再走表格
    粘贴（同样拆行覆盖）；现在改为把剪贴板内容插入编辑框光标处，未完成的
    编辑不丢。Ctrl+V 与顶部编辑栏粘贴本就整段进格，三条粘贴路径行为归一。
