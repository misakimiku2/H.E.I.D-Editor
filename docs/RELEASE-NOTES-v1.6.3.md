# H.I.D.E v1.6.3

> 发布于 2026 年 11 月 11 日 · 标签 `v1.6.3` · 桌面与安卓

这一版把 Markdown 从「能打开大文件」推进到「大文件也能顺畅阅读和查找」：百万字符级文档分块预览、Rust 全文查找、只读极速预览与索引后台预热；同时补了一批 Markdown 写作手感和交互修复。

## 新功能

- **超大 Markdown 分块预览**：超过 15 万字符按标题切块，首屏只渲染前 8 块，滚动到哪加载到哪；打开 3.7MB 文档首屏约百毫秒，不再整篇解析卡死
- **大文档查找换 Rust 全文索引**：Ctrl+F 不再为了查找补载全文 DOM；3.7MB 文档索引构建约 60–70ms，单次查找 1–2ms，跳转只渲染命中位置附近的内容
- **索引后台预热**：打开大文档后在空闲时预建索引，第一次 Ctrl+F 直接命中；切换/关闭标签立即释放，编辑后自动失效并按需重建
- **极速预览（只读）**：Rust 解析 + 安全清洗后输出分块 HTML，适合大文档快速通读；顶部可切换完整/极速模式，模式栏向下滚动自动收起、鼠标回到顶部再浮出
- **原始 HTML 白名单**：`<br>` 等常用标签在预览中保留，脚本、事件属性与危险协议仍会被清洗；页签组支持可视化增删改
- **代码块与链接**：代码块显示语言标签并支持一键复制；预览里的相对 `.md` 链接可直接跳转
- **写作手感**：粘贴 URL 在编辑器与预览两个入口都会自动变成链接；预览里的任务勾选可回写源码；列表/任务项回车自动续行

## 问题修复

- 修复 Markdown 预览里 Ctrl+A 全选后页面跳回顶部的问题
- 修复预览选区高亮层拦截鼠标点击的问题
- 修复长文档查找跳转时把前面所有块重新渲染、导致跳文末卡住的问题；现在只渲染目标附近
- 修复极速预览连续滚动时偶尔停在「渲染中…」的问题（渲染请求改为单飞队列）
- 修复大文档窗口中跳转后返回、完整/极速模式切换时阅读位置丢失的问题

## 安卓

- 本次安卓包是 v1.5.5 之后首次更新，一并包含 v1.5.6–v1.6.2 的界面、查找、崩溃草稿与主题修复
- 桌面专属的 Rust 全文索引与极速预览在安卓端不启用；安卓继续使用分块预览 + 预览内查找，本次已在手机与平板模拟器实测通过
- 侧载 APK 保持 v1.4 起的 release 签名，可直接覆盖安装 v1.5.5，不需要先卸载

## 说明

- 极速预览为只读模式：表格编辑、页签编辑、任务勾选回写、图片查看器暂不可用；图表/公式为静态展示，本地图片不加载（远程图片正常）
- `==高亮==` 与词内上下标在极速预览中按源码文本显示；切回完整预览即可看到渲染效果
- 超长文档仍采用窗口化渲染：为保持流畅，跳转到远处时只加载当前位置附近，上方的更早内容可用大纲或再次查找跳转
