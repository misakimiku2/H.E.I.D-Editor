# H.I.D.E v1.3.2 发行说明

> 发布日期：2026-09-18 · 标签：`v1.3.2`

## 主题：大目录场景可用性

本补丁面向「数万文件的工作目录」（游戏提取输出、语料库这类场景）：把跨文件搜索
从半小时级的黑盒等待压缩到秒级可见，文件树打开与大目录浏览不再冻结，并给搜索
装上了进度与取消。

### 跨文件搜索

- **速度**：三重提速——二进制文件改为头部采样识别（数 GB 的音频资源不再整读后
  丢弃）、大小写不敏感匹配免去逐行重复分配、扫描改多线程并行。数万文件的真实
  目录实测从 30 分钟级降到 **3 秒级**。
- **进度与取消**：搜索中实时显示「已扫描 N / M 个文件 · 命中 K 处」，随时可取消，
  取消后立即回到可用状态，不再黑盒干等。
- **结果上限**：单次可浏览命中从 5,000 条提升到 **20,000 条**（此前 7,000 条命中
  只能翻 50 页，其余永远翻不到）；超出上限时明确提示「已达上限，显示 X / 共 Y 处」。

### 文件树

- **大目录秒开**：目录行改虚拟化渲染——数千文件平铺的单层目录展开不再卡死整窗，
  只渲染可视区域，滚动流畅。
- **打开侧栏不再冻结**：修复目录自动刷新监听建立时会同步扫描全树的问题（数万
  文件目录曾致整窗冻结约 8.5 秒），现在亚毫秒建立；外部增删改仍自动刷新。

### 启动与其他

- **启动体验**：窗口改为加载完成后带内容显示，消除启动白屏与空界面闪帧；前端
  异常时有看门狗兜底，窗口不会永不出现。
- 只读预览（更新文档等）右键不再弹出浏览器默认菜单。
- 工程侧：Release 上传改用 gh CLI，规避 windows-latest 上传组件的资产缺陷。
