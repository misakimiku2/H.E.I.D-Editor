# H.I.D.E v1.4.1

> 发布于 2026 年 9 月 22 日 · 标签 `v1.4.1`

本版是 v1.4 安卓触屏适配的收尾，加一轮真机反馈的修复。改动几乎全在安卓端。

## 新功能

- 新增了 SVG 元素位移 X / Y 输入框与 ± 步进按钮，一步 1 个 SVG 用户单位（桌面、平板同见）。
- 新增了「跳转到行」的触屏入口，放在查找栏里的 `#` 开关。
- 新增了平板菜单栏的查找按钮，查找栏在平板上整幅停靠、保持桌面同款的一行布局。
- 手机端设置页改成了整页显示，开关、分段、下拉按触屏尺寸重做，字号滑杆换成 − / + 步进。
- 手机端文件树从覆盖式抽屉改成了推拉式侧栏，不遮住编辑区，并支持左滑收起。
- 优化了 Markdown 表格的行列增删工具条，按钮尺寸抬到触屏达标档。
- 优化了平板端触点，菜单栏与状态栏里 44 / 48dp 混排的一档统一到 48dp。
- 优化了手机端溢出菜单，去掉与底部工具栏重复的项；抽屉里的关闭标签按钮撑到 48dp，成为手机端唯一的关标签入口。

## 问题修复

- 修复了安卓真机上编辑器回车没反应、不换行的问题。
- 修复了系统 WebView 内核较老（Chrome 99，如部分华为机型）时界面崩坏的问题：边框变实线、页面高度塌陷、毛玻璃消失、居中浮条偏移。
- 修复了查找 / 替换栏被键盘压在下面、手机上显示不全的问题。
- 修复了点击查找栏上的按钮（展开替换、上一个 / 下一个）后输入法收起、不再自己弹出的问题。
- 修复了 Markdown 表格工具条在键盘弹出那一刻被推到键盘底下、等于按钮消失的问题。
- 修复了表头是唯一行 / 唯一列时点「−」仍把文件标成未保存的问题。
- 修复了部分设备上系统「打开方式」里选不到 H.I.D.E 的问题（文件关联）。

> v1.4.0 → v1.4.1 是同一把签名，**直接覆盖安装即可**，不用卸载；装过 v1.3.x 及更早 debug 包的设备需先卸载一次。
> 桌面端只有属性页新增的那两行，不需要在触屏设备上干活可以跳过本版。
